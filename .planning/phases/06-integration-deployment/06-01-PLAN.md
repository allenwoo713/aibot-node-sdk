  <action>
    Modify the Dockerfile production stage (the second FROM node:22-alpine stage):

    1. REMOVE this line from the production stage:
       ```
       RUN pnpm install --prod --frozen-lockfile
       ```

    2. ADD this line AFTER `COPY --from=builder /app/dist ./dist`:
       ```dockerfile
       COPY --from=builder /app/node_modules ./node_modules
       ```

    The production stage should now look like:
    ```dockerfile
    # Production stage
    FROM node:22-alpine

    WORKDIR /app

    # Install pnpm
    RUN npm install -g pnpm

    COPY package.json pnpm-lock.yaml* ./
    COPY --from=builder /app/dist ./dist
    COPY --from=builder /app/node_modules ./node_modules

    ENV NODE_ENV=production

    EXPOSE 3000

    CMD ["node", "dist/bot/entry.js"]
    ```

    Rationale: better-sqlite3 is a native addon compiled during `pnpm install` in the builder stage (which has python3, make, g++). Copying the pre-built `node_modules` avoids recompilation in the production stage, which lacks build tools.
  </action>
