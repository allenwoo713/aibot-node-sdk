# Plan 11-01: WeComApiClient Schedule and Document Method Tests

## Goal
Add direct unit tests for `createSchedule`, `getSchedule`, and `getDocContent` in `src/api.test.ts`.

## Tasks

1. **Add `createSchedule` test**
   - Mock TokenManager to return a token
   - Mock axios.request to return `{ errcode: 0, schedule_id: 'sched-123' }`
   - Assert `client.createSchedule(scheduleData)` returns the response
   - Assert the request body contains `{ schedule: scheduleData }`

2. **Add `getSchedule` test**
   - Mock TokenManager to return a token
   - Mock axios.request to return `{ errcode: 0, schedule: { ... } }`
   - Assert `client.getSchedule('sched-123')` returns the schedule data

3. **Add `getDocContent` polling test**
   - Mock TokenManager to return a token
   - Mock first axios.request to return `{ task_done: false, task_id: 'task-1' }`
   - Mock second axios.request to return `{ task_done: true, content: '# Doc' }`
   - Assert `client.getDocContent('doc-123')` returns `'# Doc'`
   - Assert two requests were made with correct body progression

## Verification

- New tests cover the three missing WeComApiClient methods
- No existing tests broken
