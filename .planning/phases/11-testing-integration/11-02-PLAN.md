# Plan 11-02: E2E Document Command Test

## Goal
Add an end-to-end test for the `/文档` command through `BotOrchestrator`.

## Tasks

1. **Create `__tests__/bot.document.e2e.test.ts`**
   - Reuse the mock setup from `__tests__/bot.e2e.test.ts` (mock WSClient, AnthropicApiAdapter, generateReqId)
   - Mock `WeComApiClient.getDocContent` to return `'# Test Document\nContent'`
   - Mock AI adapter.chat to return `{ content: '文档总结：这是一个测试文档。' }`
   - Send a `message.text` frame with `text.content: '/文档 doc_123'`
   - Assert AI adapter.chat was NOT called for the command path (document handler calls it, but the routing goes through handleCommand)
   - Assert `replyStream` was called with the summarized content

2. **Add error-path E2E test**
   - Mock `getDocContent` to throw `'Document content polling timed out'`
   - Send `/文档 doc_123`
   - Assert `sendText` is called with timeout error message `'文档处理超时，请稍后重试。'`

## Verification

- `npx vitest run __tests__/bot.document.e2e.test.ts` passes
- Command routing works end-to-end through BotOrchestrator
- Error fallback propagates correctly to the user
