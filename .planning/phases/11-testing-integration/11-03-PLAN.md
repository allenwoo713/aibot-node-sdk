# Plan 11-03: E2E Schedule Command Tests

## Goal
Add end-to-end tests for `/日程 创建` and `/日程 列表` through `BotOrchestrator`.

## Tasks

1. **Create `__tests__/bot.schedule.e2e.test.ts`**
   - Reuse the mock setup from `__tests__/bot.e2e.test.ts`
   - Mock `WeComApiClient.createSchedule` to return `{ errcode: 0, schedule_id: 'sched-e2e' }`
   - Send a `message.text` frame with `text.content: '/日程 创建 明天下午3点团队周会'`
   - Assert `createSchedule` was called with correct organizer, attendees, summary
   - Assert `replyStream` was called with confirmation containing `'已创建日程'` and `'团队周会'`

2. **Add `/日程 列表` E2E test**
   - Pre-seed `ScheduleStore` with one upcoming entry
   - Send `/日程 列表`
   - Assert `replyStream` was called with list containing the seeded schedule summary

3. **Add schedule error-path E2E test**
   - Mock `createSchedule` to return `{ errcode: 40001, errmsg: 'invalid credential' }`
   - Send `/日程 创建 明天下午3点团队周会`
   - Assert `replyStream` was called with `'日程创建失败，请稍后重试。'`

## Verification

- `npx vitest run __tests__/bot.schedule.e2e.test.ts` passes
- `/日程 创建` end-to-end flow works through BotOrchestrator
- `/日程 列表` returns stored schedules
- API errors surface user-friendly messages
