    1. `export interface ScheduleExtractionResult`:
       ```typescript

         title: string;
         start_time: number; // Unix timestamp seconds
         end_time: number;   // Unix timestamp seconds
       }
       ```

    2. `export function parseScheduleDescription(description: string): ScheduleExtractionResult | null`
       - **Layer 1 (Regex fast path):** Parse high-confidence Chinese temporal patterns locally.
         - Date keywords: `今天` (today), `明天` (tomorrow), `后天` (day after tomorrow), `下周X` (next weekday X where X is 一–日), `下下周X` (weekday after next).
         - Time patterns: `X点` (hour), `X:XX` or `X.XX` (hour:minute), `半小时` (duration 30min), `一小时` (duration 60min).
         - Default time when only date is present: 09:00.
         - Default duration when no end time/duration is present: 1 hour.
         - Build `start_time` and `end_time` using the local server timezone (standard `Date` object).
         - Extract `title` by removing matched date/time expressions from the description and trimming. If the remaining text is empty, use the original description as title (max 20 chars).
         - If regex produces valid start_time and a non-empty title, return the result.
       - **Layer 2 (AI extraction fallback):** If Layer 1 returns null, do NOT call AI in this function. The function returns `null` to signal that the caller (schedule command handler in a later plan) should perform AI extraction.
         - Rationale: `parseScheduleDescription` must remain synchronous and not depend on `AiBackend`.
       - **Layer 3 (User prompt fallback):** Also signaled by returning `null`. The caller will reply to the user asking for clarification.

    3. Helper functions (private or exported at your discretion):
       - `parseChineseDate(description: string): Date | null` — resolves date keywords to a concrete `Date`.
       - `parseChineseTime(description: string): { hour: number; minute: number; durationMinutes: number } | null` — resolves time and duration.
       - `buildResult(title: string, baseDate: Date, hour: number, minute: number, durationMinutes: number): ScheduleExtractionResult` — computes Unix timestamps.

    4. Title extraction rules:
       - Remove matched date/time substrings from the original description.
       - Trim whitespace.
       - If empty, fall back to original description truncated to 20 characters.

    5. Do NOT import `AiBackend` in this file. Keep it pure (no async, no AI dependencies).
  </action>
