## Research-derived contract

HealthServer constructor signature (per RESEARCH.md):
```typescript
constructor(private isHealthy: () => boolean)
```

Methods:
- `start(port = 3000): void` — creates `http.createServer`, listens on port
- `stop(): Promise<void>` — closes server

Route behavior:
- `GET /health` → `200 OK` `{ "status": "healthy" }` if `isHealthy()` is true
- `GET /health` → `503 Service Unavailable` `{ "status": "unhealthy" }` if `isHealthy()` is false
- Any other path or method → `404 Not Found` (empty body or minimal)

    Create `src/health.ts` exporting a `HealthServer` class with the following exact specification:

    1. **Constructor**: `constructor(private isHealthy: () => boolean) {}`
    2. **Private field**: `private server: http.Server | null = null`
    3. **Method `start(port = 3000): void`**:
       - Create `http.createServer((req, res) => { ... })`
       - If `req.url === '/health' && req.method === 'GET'`:
         - Call `this.isHealthy()`
         - If true: `res.writeHead(200, { 'Content-Type': 'application/json' })` then `res.end(JSON.stringify({ status: 'healthy' }))`
         - If false: `res.writeHead(503, { 'Content-Type': 'application/json' })` then `res.end(JSON.stringify({ status: 'unhealthy' }))`
       - For all other paths/methods: `res.writeHead(404).end()`
       - Call `this.server.listen(port, () => { console.log(\`Health server listening on port ${port}\`); })`
    4. **Method `stop(): Promise<void>`**:
       - Return `new Promise((resolve) => { if (!this.server) { resolve(); return; } this.server.close(() => resolve()); })`
    5. Use `import http from 'node:http'` at the top of the file.
    6. Do NOT add any other routes, middleware, or dependencies.
    7. Do NOT expose version numbers, config values, or internal state beyond the boolean `status` field.
  </action>
