## PERSIST — Async Persistence

- [x] **PERSIST-01**: `ConversationStore` 的所有磁盘 I/O（读/写）改为异步，不再阻塞 Node.js 事件循环 — *validated*
- [x] **PERSIST-02**: 引入内部写队列，保证同一时刻只有一个磁盘写入在执行，防止 JSON 文件损坏 — *validated*
- [x] **PERSIST-03**: 移除构造函数中的同步 `fs.readFileSync`，改为延迟/显式初始化 — *validated*
- [x] **PERSIST-04**: 保持现有 JSON 文件格式，不破坏已有部署的数据兼容性 — *validated*
- [x] **PERSIST-05**: 保留 corrupt-state 恢复行为（文件损坏时静默忽略，不崩溃） — *validated*

## TRANSPORT — HTTP Fallback

- [x] **TRANS-01**: 新增 WeCom HTTP API 发送消息能力，作为 WebSocket 不可用的 fallback — *validated*
- [x] **TRANS-02**: 实现 access_token 的内存缓存与过期自动刷新机制 — *validated*
- [x] **TRANS-03**: 暴露框架无关的 HTTP callback 处理器（`handleCallback(req, res)`），接收 WeCom 推送的消息/事件 — *validated*
- [x] **TRANS-04**: HTTP 回调支持 WeCom 的 SHA1 签名验证和时间戳 freshness 检查 — *validated*
- [x] **TRANS-05**: HTTP 回调支持 AES-256-CBC 解密，并将 payload 标准化为 `WsFrame`，流入现有 `MessageHandler` — *validated*

## COMPAT — Backward Compatibility

- [x] **COMPAT-01**: `ConversationStore` 的公开 API 签名保持向后兼容（外部消费者无需修改） — *validated*
- [x] **COMPAT-02**: `BotOrchestrator` 内部调用改为 `await` Store 的异步方法 — *validated*
- [x] **COMPAT-03**: 新增 `Transport` 接口，WebSocket 与 HTTP 统一抽象；`BotOrchestrator` 不感知底层传输 — *validated*

## TEST — Coverage
